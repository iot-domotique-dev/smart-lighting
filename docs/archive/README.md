Pour l’état courant, commencer par le [README du projet](../../README.md), puis utiliser les [références actives](../README.md).

- [Contexte V2.7](PROJECT_CONTEXT_V2_7.md) : historique du développement jusqu’à V2.7.
- [Contexte V2.9](PROJECT_CONTEXT_V2_9.md) : instantané de l’architecture V2.9.
- [Audit pré-V7](AUDIT_PROJET_PRE_V7.md) : constats de l’ancien dépôt avant les profils C6 et la validation V5.
- [Conception du pairing V4](V4_PAIRING.md) : modèle logiciel antérieur à son intégration au firmware V5.

Ne pas suivre les commandes de build, les listes de profils ou les « prochaines étapes » de ces archives comme s’il s’agissait de l’état actuel.
